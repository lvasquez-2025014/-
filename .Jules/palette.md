## 2023-10-24 - Missing Native Hover States for ImGui Custom Elements
**Learning:** Custom ImGui interactive elements (like `ImGui::InvisibleButton`) and text links using `ImGui::Selectable` do not have native visible cursor hover states by default. This makes it difficult for users to discover interactive areas without visual cues. The boolean parameter in `ImGui::Selectable` only tracks selection, not hover state.
**Action:** When implementing custom buttons or links in ImGui using `InvisibleButton` or `Selectable`, always manually check `ImGui::IsItemHovered()` immediately after the element's declaration and apply `ImGui::SetMouseCursor(ImGuiMouseCursor_Hand)` to provide explicit interactive feedback. Apply subtle visual styling changes (like background color shifts) if appropriate.
