## 2024-03-24 - ImGui Custom Interaction Hover States
**Learning:** In this project's UI, custom ImGui interactive elements like `ImGui::InvisibleButton` and text links configured with `ImGui::Selectable` lack native visible hover states (like the hand cursor or underline styling). Furthermore, the boolean parameter passed to `ImGui::Selectable` tracks the *selection/activation* state, not the real-time *hover* state.
**Action:** Always implement hover effects manually for these elements. Use explicit cursor changes via `ImGui::SetMouseCursor(ImGuiMouseCursor_Hand)` checked via `ImGui::IsItemHovered()`, and bind visual style changes (like drawing underlines) to `ImGui::IsItemHovered()` rather than the interaction boolean of the selectable. State checks must be placed immediately after the UI element declaration.
